# StockScanTool

A .NET tool for scanning and managing inventory.

## Branches

| Branch | Purpose |
|--------|---------|
| `main` | Production-ready code |
| `dev`  | Active development — branch from here |
| `test` | UAT and manual functional testing |

## Getting Started

### Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) or later

### Build

```bash
dotnet build
```

### Run

```bash
dotnet run --project src/StockScanTool
```
